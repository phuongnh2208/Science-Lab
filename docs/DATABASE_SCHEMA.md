# Database schema

Theo tài liệu phân tích, database Supabase đã có các bảng:

`profiles`, `education_levels`, `grades`, `subjects`, `textbook_series`, `chapters`, `lessons`, `class_profiles`, `experiment_kits`, `kit_items`, `class_equipment`, `resources`, `lesson_contents`, `lesson_resources`, `lesson_plan_templates`, `lesson_plans`, `public_shares`.

Ứng dụng không tự tạo lại, xóa hoặc đổi tên các bảng này. Việc kiểm tra schema thực tế và các migration bổ sung sẽ được thực hiện sau khi có quyền truy cập project Supabase.
